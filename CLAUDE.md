# Working rules

- **Commit and push when work is done.** As soon as a task or feature is complete and working, commit it and push it, without waiting to be asked. Working means the tests pass and, if the change can be seen in the running app, it's been checked there. Don't commit or push unfinished or failing work.
- **Keep tooltips short.** A few words or a figure per line, like "TOU 25% pwr". No sentences or prose; longer explanations belong on the page, not in a tooltip.
- **The repo is public.** Before every commit, check the staged changes for secrets and personal data, such as the inverter's IP or serial number.
